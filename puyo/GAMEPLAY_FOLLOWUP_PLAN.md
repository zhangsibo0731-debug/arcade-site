# 噗呦噗呦 · 游戏性复查后续计划

更新日期：2026-09-30  
状态：H1、H2 与 V3-P1 已完成；下一步实现 Stage 20 通关节点  
范围：挑战模式的奖励连锁反馈、坚固干扰、通关节点与后期清障平衡观察

## 1. 当前结论

- 清道夫已限制为玩家正常回合首次清除相邻干扰时触发一次。
- Stage 清障形成的奖励连锁不会再次触发清道夫，但仍可计分并触发彩色爆破。
- Stage 完成清障已改为按结算前棋盘占用率清除 `2 / 3 / 4` 颗，特殊关总上限为 4。
- 当前没有阻止上线的正确性问题；后续重点是修正奖励连锁反馈，并用实玩数据判断是否继续削弱自动清障。

## 2. 确定要做

### H1：统一奖励连锁的结果反馈（✅ 已完成）

当前连锁总结会在 Stage 清障前出现。如果清障后的重力形成新连锁，最终得分和最高连锁会继续增长，但已显示的总结不会更新。

实施目标：

- 玩家原始连锁、Stage 清障和由此形成的奖励连锁全部结束后，再显示一次最终总结。
- 奖励连锁继续沿用当前连锁编号、得分、音效和最高连锁统计。
- 总结中明确标记“奖励连锁”，避免玩家误以为它完全由本次摆法自然形成。
- 没有奖励连锁时，维持当前反馈节奏，不额外延迟普通结算。
- 升级选择、契约选择和下一组生成必须等待最终总结结束，不能抢先弹出。

验收：页面显示的 Chain、结算得分和实际纪录一致；普通连锁的等待时间不变。

### H2：补完整回合生命周期回归测试（✅ 已完成）

覆盖以下完整流程：

```text
玩家落子
→ 多段连锁
→ 清道夫最多触发一次
→ Stage 完成清障
→ 奖励连锁不触发清道夫
→ 彩色爆破仍可触发
→ 下一组落下后清道夫额度恢复
```

同时验证：

- 奖励连锁不推进新任务，不触发全消奖励。
- 奖励连锁仍可计分并更新最高连锁。
- 暂停、退出和恢复不会保存半途的清道夫临时状态。
- 旧存档无新增字段也能正常继续。

## 3. 先观察，不立即修改

### V3-P1：坚固干扰（✅ 已完成）

- 普通干扰受到一次有效清障即消失。
- 装甲干扰第一次受击变为裂纹状态，第二次受击才消失。
- Stage 8 起，投放至少 2 颗时混入 1 颗装甲干扰。
- Stage 15 起，单批投放 4 颗时混入 2 颗装甲干扰。
- 临界空间单批上限为 1 时仍只落普通干扰，避免无解惩罚。
- 三种干扰共用空中坠落、延迟和落地反弹，但拥有清晰不同的外观。
- 邻接清除、清道夫、彩色爆破、Stage 奖励清障统一经过同一套受击规则。
- 存档、棋盘查找、重力、粒子和渲染均已支持三种干扰值。

### V3-P2：Stage 20 通关节点（下一步）

- 完成 Stage 20 后显示一次明确的挑战通关总结。
- 展示得分、最高连锁、构筑方向和已完成任务数。
- 提供“继续无尽”和“结束本局”两个选择。
- 继续无尽保留当前棋盘、强化、遗物和分数，Stage 21 后沿用现有任务生成。
- 通关弹窗及其选择必须可安全保存/恢复，不能因刷新重复领奖或丢失模式。
- 不影响经典模式，也不把 Stage 20 设为强制结束。

### H3：Stage 完成后的整批延期

当前只要 Stage 奖励实际清除至少一颗干扰，本回合到期的整批干扰就会延后一组。它与 `2 / 3 / 4` 颗自动清障叠加后，可能仍让后期压力偏低。

先记录至少 10 局 Stage 8 以后实玩结果，关注：

- 完成任务后连续多少回合没有实际干扰落下；
- 延后债务是否经常被后续连锁完全抵消；
- 玩家处于拥挤或临界棋盘时，Stage 奖励是否频繁直接脱险。

若仍明显偏简单，优先改为“只延后与本次自动清除数量相同的到期干扰”；不直接取消 Stage 奖励，也不改变现有 `4 / 2 / 1` 投放上限。

### H4：彩色爆破的逐段触发

彩色爆破当前可在每段满足大团条件的连锁中各触发一次。先保留这项流派特色，仅在大团流能够长期清空全部干扰时调整。

若需要削弱，首选“每次落子最多触发两次”，而不是像清道夫一样限制为一次，避免两项强化失去差异。

## 4. 低优先级整理

### H5：区分干扰统计来源

结算页“清除干扰”目前包含玩家邻接清除、强化清除和 Stage 自动清障。后续可拆成：

- 玩家清除干扰；
- 自动清障；
- 本局总清障。

该项只改善统计表达，不改变任务进度、分数或难度，排在游戏性工作之后。

## 5. 推荐顺序

```text
H1 奖励连锁总结
→ H2 完整生命周期测试
→ 实玩采样
→ 仅在数据确认后执行 H3 / H4
→ H5 统计整理
```

本计划不包含手机信息层级重做、对战模式、新主动道具或新的肉鸽强化。
