# Project Instructions

## CodeGraph

When a `.codegraph/` directory exists, use CodeGraph before grep/find or reading source files when locating or understanding code. Prefer `codegraph explore "<question or symbols>"`, then fall back to other tools as needed.

## GitHub Push Policy

- After making project changes, ask the user whether they want the changes committed and pushed to GitHub.
- By default, keep changes local. Do not commit or push unless the user explicitly approves it.
- Never infer push approval from a request to edit, fix, build, test, or finish the project.
