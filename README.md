# 月夜街机 · 游戏厅

一个适配手机与桌面浏览器的个人网页游戏厅。打开网页即可游玩，也可以添加到手机主屏幕，以接近独立应用的方式启动。

**在线体验：** [zhangsibo0731-debug.github.io/arcade-site](https://zhangsibo0731-debug.github.io/arcade-site/)

## 当前游戏

| 游戏 | 简介 |
| --- | --- |
| 数独 | 经典与儿童模式，支持提示、笔记和进度保存 |
| 俄罗斯方块 | 经典落块、Hold、Next 与移动端连续输入 |
| 噗呦噗呦 | 经典连锁及带任务、干扰和构筑的挑战模式 |
| 吃豆人 | 迷宫吃豆、能量豆与幽灵追逐 |
| 打砖块 | 多关卡、道具与连续击打反馈 |
| 2048 | 滑动合并、撤销与本地最高分 |
| 记忆翻牌 | 轻量的卡片配对游戏 |
| 月光垂钓 | 多钓场、鱼类图鉴、鱼篓、商店、装备与成就 |

## 特性

- 响应式布局，支持触屏、键盘和桌面浏览器；
- 可安装为 PWA，已缓存的内容可在离线时继续使用；
- 游戏进度、图鉴和大部分纪录保存在浏览器本地；
- 噗呦挑战模式提供自愿加入的云端周排行榜；
- 无账号也能游玩，云服务不可用时不会影响游戏本体和本地纪录。

## 添加到主屏幕

### iPhone / iPad

1. 使用 Safari 打开在线体验地址；
2. 点击底部的“分享”；
3. 选择“添加到主屏幕”；
4. 确认名称后点击“添加”。

### Android

1. 使用 Chrome 打开在线体验地址；
2. 打开浏览器菜单；
3. 选择“安装应用”或“添加到主屏幕”；
4. 按提示完成安装。

浏览器数据按域名隔离。更换域名、清除网站数据或卸载浏览器，可能导致本地存档无法继续读取。

## 本地运行

项目不需要前端构建步骤。在仓库根目录启动一个静态文件服务器：

```bash
python3 -m http.server 8417
```

然后访问：

```text
http://127.0.0.1:8417/
```

请不要直接双击 `index.html` 以 `file://` 打开，否则 Service Worker、模块加载及部分浏览器能力可能无法正常工作。

## 数据与隐私

- 游戏存档默认只保存在当前浏览器的 `localStorage`；
- 只有玩家主动设置昵称并开启排行榜后，噗呦挑战成绩才会上传；
- 排行榜上传内容包括本地玩家标识、昵称、分数、Stage、最高连锁、游戏时长和版本；
- 云排行榜故障时会自动退回本地体验，不会阻止游戏运行。

## 开发与部署

- 静态游戏页面由 GitHub Pages 发布；
- 排行榜以 Cloudflare D1 为唯一数据源；
- CloudBase 网关是国内主要入口，Cloudflare Worker 是备用入口；
- 服务端通过 GitHub Actions 手动部署，部署前会运行测试，部署后会检查线上接口。
